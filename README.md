Português 🇧🇷 - Automação pós-instalação do Linux Mint focada em jogos, emulação e uso diário.

English 🇬🇧- Linux Mint post-install automation focused on gaming, emulation and daily usage.

Uso diário

⚡ Instalação
-
Clone o repositório:

git clone https://github.com/Carlin20033451/linux-mint-gamer-setup.git

Entre na pasta:

cd linux-mint-gamer-setup

Dê permissão de execução:

chmod +x mint-gamer-setup.sh

Execute:

./mint-gamer-setup.sh
